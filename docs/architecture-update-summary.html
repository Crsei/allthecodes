What remains

没有把计划写成已完成

  1. 工具执行边界仍过宽，需要 ToolExecutionPlan / ToolExecutionPipeline 收敛 validation、hook、permission、sandbox、audit 与 runtime record。
  2. Query / submit 生命周期仍需状态机化，目标是 QueryTurnState、恢复策略模块和 SubmitTransaction。
  3. Session / record-replay 真相源仍在迁移，方向是 JSONL transcript truth + SQLite index/query cache + legacy JSON 兼容输入。
  4. API / IPC dispatcher 仍有 legacy adapter；allthecodes-protocol 已有基础，但完整 dispatcher、WebSocket IPC 和传输层抽象还要继续接入。
  5. Hook 系统需要补齐行为矩阵，Full Build 阶段不能保留静默 success placeholder。
  6. MCP bridge dependency health 仍是计划状态，需要 proof-of-life/probe、错误分类、retry/circuit breaker 和 UI/IPC 状态面。
