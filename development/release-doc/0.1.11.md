# allthecodes 0.1.11

## Runtime And TUI

- Added centralized runtime metadata and policy guardrails for command, tool, and runtime state surfaces.
- Split TUI app state into domain stores, refreshed task snapshots from runtime state, and centralized overlay dispatch/outcome handling.
- Completed command operation display wiring and added operation renderer metadata.
- Added runtime view state and message view model plumbing for the Rust TUI.

## ACP Adapter

- Added ACP stdio smoke tests and aligned ACP session lifecycle, prompt updates, prompt acknowledgement ordering, permissions, cancellation, config, auth, and command exposure.
- Corrected ACP capability gates and documented ACP adapter support and review fixes.

## MCP And Auth

- Added MCP OAuth auto-auth and hardened MCP HTTP OAuth web and credential flows.
- Implemented MCP scope isolation and cleaned pending OAuth state.
- Added dependency recovery health checks for bridge and daemon startup diagnostics.

## Record Replay, Cost, And API

- Added record replay core, telemetry support, migration/index/redaction tests, and persisted worktree session records.
- Added P1 file and git API endpoints plus typed IPC P0 route coverage.
- Added tests for extra usage cache scenarios and reasoning token accounting.
