# allthecodes 0.1.12

## Runtime Security And Verification

- Added taint-aware workflow-injection controls, bounded verification policies,
  and redacted, integrity-linked session reports.
- Prevented compound, masked, interrupted, and non-zero shell commands from
  being accepted as positive verification evidence.

## Delegation, Automation, And TUI

- Completed delegated Agent execution bridging and expanded daemon automation,
  proactive scheduling, and Rust TUI runtime-state coverage.
- Added bounded Team Memory proxy I/O and sharded PTY end-to-end test support.

## Release Validation

- `cargo build --workspace --release --locked`
- Verified `allthecodes --version` reports `0.1.12`.
