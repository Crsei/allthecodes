# allthecodes 0.1.7

## Desktop Account Billing

- Added local daemon support for desktop account billing status fields from allthecodes.cc auth responses.
- Account auth status now preserves `credits` and `agent_collaboration` so local Web surfaces can show plan, credit balance, reserved credits, usage, and collaboration limits without exposing account tokens to browser storage.
- Added daemon-side read-only billing proxy endpoints for account billing snapshots, credit ledger pages, and payment order details.
- Billing proxy requests use the in-memory allthecodes account access token and refresh once on authorization failure.

## CI/CD

- Updated GitHub Actions CI triggers so pushes to the active `allthecodes` branch run the `ci` workflow.
- The release workflow now asks GitHub to generate release notes for tagged releases.

## Verification

- `npm run typecheck` in `allthecodes-com`
- `npm run typecheck` in `allthecodes-web`
- `cargo check -p allthecodes-daemon`
- `git diff --check`
