# allthecodes 0.1.6

## Feedback Integration

- Added `/feedback` slash command in `allthecodes` to open the allthecodes product feedback page with `source=tui` and the current package version.
- Updated `allthecodes-web` feedback entry points to open the shared website feedback page instead of sending a local settings action.
- Updated `allthecodes-com` feedback form to preserve an incoming `pageUrl` query parameter when submissions originate from another allthecodes surface.
- Fixed the `allthecodes-commands` insights test fixture to include `chat_mode_override`, keeping the command crate tests compiling with the current session schema.

## Verification

- `cargo test -p allthecodes-commands feedback`
- `cargo build --workspace --release`
- `allthecodes-web`: `npm run typecheck`, `npm run build`
- `allthecodes-com`: `npm run typecheck`, `npm run build`
