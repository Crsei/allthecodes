# allthecodes 0.1.14 Release Build Plan

## Goal

Prepare the repository metadata for version `0.1.14` and produce a verified,
locked workspace release build. This task does not publish an npm package, tag,
or GitHub release.

## Scope

- Update the Rust package version and the matching root lockfile entry.
- Update the npm wrapper version and all six platform optional-dependency
  aliases.
- Add `development/release-doc/0.1.14.md` with the release validation record.
- Run `cargo build --workspace --release --locked`, then verify the release
  executable reports `0.1.14`.

## Isolation And Completion

- Make the version and release-record changes in worktree
  `worktree/release-0.1.14-build`.
- Record the worktree workflow artifact, commit the scoped changes, fast-forward
  them into `allthecodes`, and push the branch.
- Preserve every pre-existing change in the main working tree.
