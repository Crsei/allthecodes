# Allthecodes TUI 集成字形手工修改稿

> 用途：这是 `brand_logo.rs` 中 `WORD` 字形表的可视化编辑稿，方便手工调整
> `ALLTHECODES` 的每个字母形态。**运行时不会读取本文件**；确认修改后，需要把
> 对应的 `rows` 数组同步回
> [`brand_logo.rs`](../../crates/allthecodes/src/ui/components/brand_logo.rs)，并更新快照。

## 编辑规则

- 每个字母是一个 6×6 单色子像素矩阵。
- `█`（或位值 `1`）表示填充，`·`（或位值 `0`）表示空白。
- 每一行的六个 bit 从左到右读取，存放在 `u8` 的低六位。例如 `··██··` 是
  `0b001100`。
- 渲染器会把每个 2×2 子像素分为一个逻辑格，因此 6×6 数据最终显示为 3×3 九宫格；
  同一逻辑格可使用局部 half-block 形状，不要求整格填满。
- 单词顺序固定为 `A L L T H E C O D E S`。第二个 `L` 与第二个 `E` 目前复用
  相同形态，但仍保留独立位置，确保动画索引不丢失。

## 同步检查清单

完成手工调整后，将每个代码块中的 6 个二进制行复制至 `WORD` 对应的 `Glyph { rows: [...] }`
条目，并运行：

```bash
cargo test -p allthecodes --bin allthecodes ui::brand_logo::tests -- --nocapture
cargo test -p allthecodes --bin allthecodes ui::welcome::tests -- --nocapture
```

字形稳定态或动画关键帧有变化时，还需要更新：

- `crates/allthecodes/src/ui/components/snapshots/allthecodes__ui__brand_logo__tests__allthecodes_integrated_glyphs.snap`
- `crates/allthecodes/src/ui/components/snapshots/allthecodes__ui__brand_logo__tests__allthecodes_logo_keyframes.snap`
