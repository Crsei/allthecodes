TUI TaskList default and stream recovery

2026-07-19 · isolated worktree worktree/tui-task-list-default-and-stream-recovery

Task goal

Replace visible TaskCreate/TaskUpdate message rows with the default ✔/◻ TaskList above the spinner, while retaining the manual Ctrl+T view control. Also recover safely from the reported Error occurred: API error: error reading OpenAI response chunk failure when an OpenAI-compatible streaming response is interrupted before any usable output is produced.

Implemented changes

  • Normal and verbose message flows suppress task mutation tool rows and their paired ToolResult rows.
  • Task mutations automatically open the spinner-adjacent TaskList and refresh its session/team-scoped snapshot after ToolResult; unrelated tools do not open it.
  • The TaskList uses ✔ and ◻ status markers by default, while Ctrl+T remains available for explicit view cycling.
  • Streaming clients use connect timeout plus per-read timeout instead of a fixed total timeout that can cut off an active SSE response.
  • OpenAI/generic/Gemini chunk-read failures retain their complete cause chain and are recognized consistently by recovery logic.
  • An empty-output chunk/idle/stall interruption may retry once on the same model. Partial tool use is never retried, preventing duplicate side effects.
  • A chunk-read interruption after text but before tool use remains an accepted partial response in this narrow fix; the broader typed retry/tombstone design remains documented separately.
