落地改动

  • auth profile 新增 request/stream retry 与 request/idle timeout policy，含默认值、范围验证、merge、schema、redacted API 和 Web API。
  • Codex HTTP timeout 只包围响应头建立；SSE body 由 300 秒 frame idle 管理，合法 heartbeat/未知 event 均刷新 idle。
  • 仅 response.completed 成功；EOF、提前 [DONE]、chunk、idle、decode 和 response.failed 使用 typed failure。
  • request retry、stream reconnect、capacity fallback 独立计数；指数退避、jitter、Retry-After、取消和 transient UI 状态已接线。
  • Codex 工具在 completed 前不执行；失败 attempt tombstone，成功 attempt 的重复 tool ID 被拒绝。
  • 每次 Codex Responses 请求建立前重新走现有 OAuth resolver；刷新失败分类为不可重试的 AuthenticationFailed，错误不包含 token。
  • print/json 共用 positional/stdin prompt 解析；print mode 最终错误写 stderr，max-turns 原因可见。
  • SDK retry、request record、durable replay 和 session report 可区分 request/stream/fallback 恢复。
