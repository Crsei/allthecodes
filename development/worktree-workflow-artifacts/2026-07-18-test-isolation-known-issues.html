6. SOP 五条（写入 CLAUDE.md / AGENTS.md）

  1. 分层验证：先 fmt / clippy / lib 单测，再 -exclude allthecodes 跑非-PTY crate，最后单独跑 -p allthecodes --test pty_tui_e2e -- --test-threads=1；禁止一开始就 cargo test --workspace。
  2. 快照一次性 batch：PTY snapshot 失败用 INSTA_UPDATE=always 一次性更新所有 .snap.new，统一审阅后一次提交；禁止「修一个 → 跑全套 → 再发现下一个」循环。
  3. 跨 worktree target 隔离：并行 worktree 各自 CARGO_TARGET_DIR=…/.tmp/atc-。
  4. 凭据/环境隔离前置守卫：涉及认证/网络/凭据的测试在夹具启动时显式隔离 CODEX_HOME / HTTP_PROXY / NO_PROXY=* / ANTHROPIC_API_KEY，强制 RUNTIME_ENVIRONMENT=test。
  5. 全仓 .workspace 测试一次任务上限 2 次：超过 2 次必须降级到分 crate 跑并写明原因；禁止「修一项就重跑全套」的无限循环。
