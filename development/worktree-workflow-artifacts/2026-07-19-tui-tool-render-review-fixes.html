TUI tool-render review fixes

2026-07-19 · isolated worktree worktree/tui-tool-render-review-fixes

Goal

Close the three defects found while reviewing the prior TUI tool-render upgrade: use the active session/team task-list scope, avoid persistent-store reads on every 16 ms UI tick, and honor the configurable app:toggleTodos keybinding instead of hard-coding physical Ctrl+T.

Plan source

development/tui/2026-07-19-tui-tool-render-review-fix-plan.md

Implemented flow

  1. Resolve the compact TaskList store from the active session and any persisted team context, using the same task-list scope precedence as TaskCreate and TaskUpdate.
  2. Initialize the runtime cache without reading persistent task state; refresh immediately when Tasks opens, force a refresh after backend tool results, and retain a five-second fallback poll while the view remains open.
  3. Dispatch app:toggleTodos through the keybinding registry and remove the physical Ctrl+T branch, so user remaps and explicit unbinding are authoritative.
  4. Add regression coverage for session scope, restored team scope, refresh throttling, and remapped/unbound task-view toggling.
