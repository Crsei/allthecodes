任务目标

  • 为 Rust TUI 增加 provider profile 的查看、创建、完整替换、激活和删除入口。
  • 统一 TUI、命令与 Web API 的无损 profile 存储，避免重命名、替换和导入时丢失配置。

  2. 实现共享原子存储、provider 运行时构造、Web/协议/命令和 Rust TUI 管理界面。
  3. 生成 backend API 文档，在隔离的前端 worktree 验证 OpenAPI 与 frontend codegen。
  4. 按 fmt、clippy、非 PTY tests、定向 tests、release build 的顺序验证。
