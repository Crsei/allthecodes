任务目标（Phase 1 范围）

离线 PTY E2E 套件历史上墙钟 1930s，大量 TestStep::Wait(Duration::from_secs(2)) 这类"等屏幕静下来"的固定等待是主要拖慢项。Phase 1 用信号化等待（WaitForScreenText / WaitForAny）替换：屏幕一命中目标文字即返回，没有命中则短 timeout 失败。不触及 #[ignore] 在线测试语义、不动并发锁（Phase 2 / Task 4）、不收紧进程收尾（Task 5）。

计划与实现

  • 计划：development/test/pty-tui-e2e-timing-plan.md（Task 1 + Task 2 + Task 3 + Task 6+7 阶段）。
  • Task 1（已完成）：在 script.rs 中加 WaitForScreenText 信号化原语；AssertNoPanic 与 SkipTrustGate 内部自带短稳定窗口。
  • Task 2（已完成）：在 11 个离线测试文件中按"看上下行"规则替换或丢弃固定 Wait。
  • Task 3（按用户决策跳过字面拆分）：test4_task_execution.rs 与 test5_compact.rs 内的拆分要求与计划 §7 非目标冲突（不改 #[ignore] 在线测试语义）；running_task_slash_commands.rs 已经全部信号化、无可拆分处。详见 README 时效策略一节。
