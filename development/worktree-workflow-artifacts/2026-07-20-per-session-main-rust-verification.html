Per-Session Worktree 主分支 Rust 验证规则

2026-07-20 · isolated worktree worktree/per-session-main-rust-verification

任务目标

统一 AGENTS.md 与 CLAUDE.md 的 Per-Session Worktree 声明：代码和文档在 worktree 中修改并提交，worktree 内禁止任何 Rust 构建或测试；候选提交合并后只在主分支验证，失败则回保留的 worktree 修复，任务全部完成后才删除 worktree。

计划来源

development/workflow/2026-07-16-per-session-worktree-workflow-plan.md。权威计划已在创建本 worktree 前由主分支 commit 6276e31d 更新。

执行流程

  1. 在主分支单独提交权威计划更新，并保留已有未提交 TUI 改动。
  2. 从该计划 commit 创建独立 worktree。
  3. 只在 worktree 修改 AGENTS.md、CLAUDE.md 和本 artifact。
  4. 提交候选文档后 fast-forward 合并到主分支。
  5. 在主分支完成所需验证；若失败，回同一 worktree 修复后再次合并。
  6. 任务完成并推送成功后才删除 worktree 和任务分支。

改动列表

  • 明确主分支不直接修改任务代码，只接收计划前置提交和 worktree 的 fast-forward 合并。
  • 明确 worktree 内禁止 cargo check、cargo build、cargo clippy、cargo test、cargo nextest 及直接 Rust 测试二进制。
  • 明确 Rust 构建和测试仅在候选提交合并后的主分支执行。
  • 明确主分支验证失败时回保留的同一 worktree 修复，并重复 ff 合并与验证。
  • 明确只有任务全部完成、验证通过并推送后才能删除 worktree。
