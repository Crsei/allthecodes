任务目标与权威计划

唯一权威计划：development/bugs/2026-07-19-codex-oauth-responses-stream-timeout-retry-fix-plan.md。

  • 消除工具完成后重复 MCP 刷新造成的 query 收尾阻塞。
  • 在下一 provider 请求前，将 assistant tool call 与 tool result 强制写入并 flush canonical rollout。
  • resume 前修复 orphan tool call/result，不自动重放已执行工具。
  • 让 Read/Edit 等文件工具跨 turn 共用 session-owned 文件状态，并拒绝 stale edit。
  • 第三次相同工具验证失败时 fail closed，避免无界工具循环。
  • 统一 provider、resume、max-turns 与 tool-loop 的非交互错误和退出语义。
